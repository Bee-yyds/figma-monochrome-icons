# 首次使用：对话配置与准备

这是给执行者的提问清单，用户在聊天中回答，不能要求用户手工填 MD。由执行者自动填写 [项目配置模板](../assets/project-config.template.md)。只问缺项，每轮1–3个相关问题。

## 第一轮：项目和文件

| 缺项 | 对话问题 | 自动核验 |
| --- | --- | --- |
| 项目不明确 | 这次图标属于哪个项目？ | 配置归属与可写目录 |
| 接入方式不明 | 沿用已有图标库，还是从零建库？ | 已有库/空文件/需新建文件 |
| 无可定位链接 | 请提供 Figma 文件或目标图标区域链接。 | 文件 Key、实际 Page、节点与权限 |
| 保存位置不明 | 配置和导出文件放在哪个项目目录？ | 路径与读写能力 |

若上下文已有链接与目录，直接展示简短摘要供纠正，不再重复收集。用户不必查技术 ID 或统计组件数。

## 第二轮：图标标准

| 缺项 | 用户提供 | 执行者读取/记录 |
| --- | --- | --- |
| 类型 | 线性或面性 | 对应分类与原稿结构 |
| 尺寸 | 准确宽高；非方形给两边 | 实际画布，不按截图像素猜 |
| 风格 | 同组正式图标链接、参考图或形状说明 | 同类型样本、视觉重量、负空间 |
| 位置 | 目标分类区域或新建意图 | 实际位置、必要创建项 |
| 线性细节 | 已有标准或对候选方案作选择 | 线宽、端点、转角、对齐；面性跳过 |
| 面性细节 | 镂空、开口和交叠要求 | 填充与可编辑负形；不套线性描边 |
| 色彩 | 现有语义色角色及主题 | 实际变量/样式、绑定与模式 |
| 辅助线 | 栅格链接或同意拟定基准 | 安全区、关键线、光学基准与是否需保留实例 |
| 命名 | 沿用规则或选择语义加尺寸 | 方形/非方形/变体约定 |

已有可读样本时由工具提取参数，不要求用户抄数值。没有匹配变量、栅格或分类时，提出最小创建项并单独列入批准包。

## 从零建库

明确文件名称、归属团队/空间和位置，再只创建本次所需的图标 Page、分类区域、语义色与栅格。基础资产和首批图标可同包分别列项批准；不要扩展成整个设计系统。

新文件先创建并核验归属，再在第一次基础资产或图形写入前建立唯一回滚点。没有正式样本就记录零样本，使用获批的参考与设计基准，不虚构历史资产。

## 环境准备

核验 Figma Web 访问、当前文件编辑能力、唯一版本保存与核验、原生几何写入、截图和本地记录能力。优先用能访问同一云端文件的连接器；缺少写入或版本历史能力时报告缺项，不能转去桌面端或导入 SVG 代替。

只在用户选择导出后，才把 SVG 输出目录及文件检查能力列为必需条件；不因暂缺导出能力阻塞只绘制的任务。不索取密码、密钥或要求把凭据写进项目配置。

## 自动形成摘要

展示项目、文件和分类、类型与尺寸、线宽或填充、语义色、辅助线、命名及仍待批准的基础项。字段标记用户提供/实时读取/候选待批准/待核验，再写入配置。

输出目录不是“总是导出”的授权。每次图标完成复查后，都执行 [绘制后的格式分支](../SKILL.md#绘制后的必经分支)。
