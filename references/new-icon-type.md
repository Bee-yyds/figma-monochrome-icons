# 老用户新增图标类型

用户在对话回答，执行者自动更新配置的独立类型条目。只补本次差异，不重复首次问卷。

## 分类判断

| 变化 | 动作 |
| --- | --- |
| 同样式、同尺寸，仅语义不同 | 沿用类型，收集本次名称、用途、参考与差异 |
| 线性/面性切换 | 新建类型条目，不覆盖旧类型 |
| 改尺寸或非方形画布 | 单独记录准确宽高，不自动缩放旧标准 |
| 同尺寸但线宽、圆角或重量体系不同 | 作为另一风格登记 |
| 使用已有主题下另一个单色角色 | 核验绑定与模式，不自动新增变量 |
| 多色、渐变、位图或插画 | 明确超出范围；仅在用户选择单色重绘后继续 |

## 用户需要提供的信息

1. 与原类型的差异：表现形式、宽高或风格。
2. 新图标的语义与用途、参考图或形状说明。
3. 必须保留与可简化的细节，例如物体数量、交叠先后、镂空及分界。
4. 同类正式资产或希望采用的风格；没有样本可直接说明。
5. 目标分类区域，或创建新分类的意图。
6. 与旧配置不同的语义色、主题、命名或例外。

可从链接、样本、附件和旧配置读到的信息由工具补齐；用户不必提供节点 ID、精确路径或绑定参数。原生选择与自由文本均在对话内完成。

## 执行者补齐的信息

读取准确画布、原稿结构、线性参数或面性负形、颜色变量/样式、安全区与辅助线、光学重心依据、样本节点、分类位置及实际数量。少于三个样本如实记录，不跨类型凑数。

缺少分类、语义色或栅格时，只提出必要基础项；规则冲突时展示差异，不能自行取平均值。不同尺寸与风格分条保存，不顺带改名旧资产或整改其他类型。

随后执行 [绘制 SOP](drawing-sop.md)。绘制批准、唯一回滚点、复查和本次格式决定不因类型改变而省略。改图后对新版本重新取得 Iconfont 决定，不能沿用旧图的接受或历史导出习惯。
