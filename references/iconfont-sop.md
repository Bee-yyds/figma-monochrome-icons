# Iconfont SVG 处理与导出

仅在当前图标已展示且用户明确需要当前版本的 Iconfont SVG 后执行。适用于获批单色线性或面性；既有组件重构、既有 SVG 更新/覆盖须明确范围。用户要求调整时先改图、复查，再取得新版本决定。

## 1. 写前复核

重读目标组件和必要依赖，核对 ID、名称、准确宽高、位置、当前图层、语义色与获批主题、栅格及用户决定时的截图。未知并发变化先暂停，不能用旧截图授权新版本。

复用本次任务已有唯一命名回滚点，不再创建命名版本。检查配置输出目录、目标文件名及同名冲突；落盘前再次检查，同名文件不自动覆盖，也不加 `_2` 绕过。

## 2. 原稿与成品

先复制当前完整原稿，置于隐藏、不锁定的 `备份` Group，保留参数、布尔结构和颜色绑定。核对分组后子层绝对位置，不能只看 Group 本地坐标。

```text
组件（ID、名称、位置、实际画布不变）
├─ Clip path group   项目要求时保留原实例，隐藏、锁定
├─ 备份              隐藏、不锁定，包含完整原稿
└─ 成品 Vector       可见；线性 Icon (Stroke)，面性 Icon
```

线性用 Figma 原生轮廓化描边生成成品；面性整理同色填充和负形。必要的合并/扁平化只作用于成品，不破坏原稿，不导入外部 SVG 或位图，也不重画已确认形状。

成品须为单个可编辑 Vector、一个复合 path，可含多个闭合子路径；无开放端点、孤立点、零长度线段或无效节点。所有子路径 `NONZERO`，孔洞靠路径方向表达。一个纯色填充继续绑定批准的现有语义变量/样式，无描边、图片、渐变、蒙版、文字或裁切结构。

## 3. 填充规则与视觉等效

优先使用可用的 Fill Rule Editor 核对 Non-zero。已经正确不切换；孔洞方向异常才修正。插件不可用时，记录 Figma 路径属性和 SVG 检查双重证据，不声称运行了插件，不反复启动或擅自安装。

比较用户决定时原稿与成品：100%、至少400%及分类总览下的轮廓、负空间、孔洞、圆角、端点、遮挡、重量、光学重心和边界必须等效。变化时停止导出，按实际情况安全恢复本次中间改动；若需改原稿，回到绘制阶段重新取得新版本决定。

## 4. 导出

从组件导出，保留实际 width、height 和 `viewBox="0 0 W H"`，不按成品紧边界裁切；特殊尺寸不变方形。仅导出组件内容，排除画布重叠、隐藏栅格和备份，关闭图层 ID，采用当前工具实际支持的等效设置。

颜色使用批准主题下语义色解析出的 sRGB 纯色，不擅自变成黑色或 `currentColor`，不切换主题获得另一颜色。工具导出结果不符合规范时修正成品/导出设置并重查，不能直接删掉会影响外观的 SVG 结构来“过检查”。

在已确认输出目录以 `{组件名称}.svg` 写入，使用不会覆盖既有文件的方式；只有实际落盘且检查通过才记为已导出。保留实际路径、字节数、SHA-256。

## 5. 检查

- XML 可解析；根元素、准确画布与 viewBox 正确。
- 只有一个必要的复合 `<path>`；每个子路径都闭合，不能只因出现一个 `Z` 就认定全部闭合。
- 默认或显式 Non-zero；无 `evenodd`、stroke、mask、clipPath、渐变、图片、文字、隐藏层、外部引用或额外背景。
- 单一纯色与本次语义色解析值一致。透明度或渲染依赖无法用当前规范等效表达时暂停说明，不偷偷改色或改外观。
- Figma 原稿备份、成品与所需栅格的结构、变量和状态均正确；无越界；相邻资产和数量保持原状。

可使用本 Skill 的只读文件检查脚本：

```bash
python3 scripts/validate_svg.py /absolute/path/icon.svg --width 24 --height 24 --color '#F2F2F2'
```

脚本检查规范化的单 path SVG，包括 XML、参数、闭合语法、颜色、禁用项及哈希；不修改文件。支持十六进制、常用命名纯色和整数 `rgb()`；不支持的颜色写法须先查明等效值，不能直接认定图形不合规。脚本不证明几何无自交、孔洞方向正确、无越界或视觉等效，这些仍须 Figma 属性与截图核验。它也不代表 Iconfont 平台实际接收。

## 6. 交付与恢复

只复扫本次分类、目标和必要依赖，保存全部创建/修改/移除节点 ID、备份/成品/栅格 ID、用户决定、唯一版本、对比截图、文件检查及真实导出路径。

全部技术检查及视觉等效通过后交付，无需第二次用户视觉确认，不自动上传 Iconfont。失败或用户撤回时停止后续处理，说明已产生的中间节点/文件；不删除用户后续变化或回滚整个正式库。
